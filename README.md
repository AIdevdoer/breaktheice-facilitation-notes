# Separate Warm-Up Questions From Evaluation

Do not use an icebreaker answer to judge performance, commitment, or team fit. State that the activity is a warm-up and keep the prompt unrelated to assessment.

If the meeting includes feedback later, make a clear transition so participants know the warm-up has ended.

For a practical starting point, use the [fun icebreaker questions collection](https://breaktheice.games/) and choose one prompt that fits the room.
